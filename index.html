Pipeline

Methodology

Eight-step reproducible pipeline from raw WMS data to implementation plan

1

Clean & Load

Robust CSV reader handles mixed delimiters, encodings, and line endings. Logs every fix in a data-quality table.

2

Rebuild Layout

2,293 locations calibrated to metres. Aisle network built for shortest-path walking distances.

3

Demand & ABC

Pick-visit demand per SKU, ABC classes (80/95%), 70/30 train/test split by wave for validation.

4

Storage Scenarios

Six policies compared: four from the case + Optimised-COI and Optimised-FAMILY designed from scratch.

5

Route Optimisation

WMS sequence, serpentine, and nearest-neighbour + 2-opt compared side-by-side.

6

Re-shuffle Plan

Only forward zone re-slotted via swaps. Class A items prioritised. 186 locations touched.

7

Statistical Testing

Paired Wilcoxon tests, sensitivity to walk speed and pick time, operator performance analysis.

8

Economics

Labour hours, FTE, and CAD/year. Full cost-benefit analysis with implementation effort.
