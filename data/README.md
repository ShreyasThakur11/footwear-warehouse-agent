# Data Directory

This folder contains the pre-computed simulation outputs, operator performance metrics, and data validation logs generated by the warehouse optimisation model.

## Files

| File | Size | Description |
|---|---|---|
| [`scenario_summary.csv`](scenario_summary.csv) | ~9.6 KB | Full benchmark comparison across 15 scenarios (6 slotting policies × 3 routing algorithms) for both ALL waves (7,341) and TEST out-of-sample waves (2,549). Contains mean/median/P90 distance, pick time, pick speed (units/hr), and percentage savings. |
| [`operator_performance.csv`](operator_performance.csv) | ~9.3 KB | Operator-by-operator evaluation for all 22 warehouse pickers. Compares historical AS-IS recorded picking vs optimal routing vs proposed Optimised-FAMILY slotting, route efficiency indices, workload shares, and individual hours saved. |
| [`data_quality.csv`](data_quality.csv) | ~2.5 KB | Audit log of 24 automated data hygiene checks (duplicate row handling, trolley capacity limit validation, shoe size decimal conversions, missing order reconciliations). |
| [`Optimised_Storage.csv`](Optimised_Storage.csv) | ~578 KB | New slotting allocation matrix mapping product references to specific bin/bay/aisle locations across pick levels 0–2 and reserve levels 3–4. |
| [`wave_level_results_all_scenarios.csv`](wave_level_results_all_scenarios.csv) | ~22.3 MB | Granular wave-level simulation results logging travel distance, number of stops, aisle visits, and estimated duration for every wave under each policy. |

## Raw Dataset

The raw customer orders, product catalog, and location coordinates originate from:
> de Assis, de Paula Ferreira & Ouhimmou (2025), *Data in Brief* 61:111837, **CC BY 4.0**. Available on Mendeley Data.
